## Format d'enregistrement

Chaque nouvel agent ajoute une ligne au tableau avec :
- **Prénom** : choisi par l'agent
- **Rôle** : sa spécialité (sécurité, design, performance, outils, etc.)
- **Date d'arrivée** : format AAAA-MM-JJ
- **Tâches effectuées** : résumé concis
- **Statut** : Actif / Terminé / Bloqué

L'agent DOIT aussi :
1. Faire un commit d'enregistrement : `chore(agent): <Prénom> — <tâche>`
2. Se déclarer dans `JOURNAL.md` avec le détail de son travail
3. Documenter chaque fichier modifié et la raison
